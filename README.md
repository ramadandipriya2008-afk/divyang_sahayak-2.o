# ScrapCycle React Frontend

## Requirements
- Node.js installed
- VS Code (recommended)

## Run
Open this folder in VS Code, open a terminal in the folder, and run:

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173).

## Notes
This is a frontend prototype. Signup, verification, pickup scheduling, and payment status are demo interactions stored in browser memory. Real authentication, persistent storage, collector dispatch, and payment processing need backend integration. Images are loaded from external URLs.
